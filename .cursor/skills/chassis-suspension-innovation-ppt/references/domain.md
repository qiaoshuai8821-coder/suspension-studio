# 悬架平台：写提案时要盯住的结构

读者是底盘工程师。这里不解释什么是控制臂，只规定提案必须点名的基线、矛盾和判据。

## 平台指什么

一套悬架平台不是“所有车用同一根衬套”。它是：铸造或焊接本体尽量一种，车身安装点尽量不动，车型之间的差别被收到少数可更换件上，而且换了之后运动学关系还在。

写范围时要说清：

- 前悬、后悬，或只做一个角模块
- 几种车高、轴距、轮距、驱动形式
- 哪些接口本次不动：车身安装点、转向节与卡钳、半轴、稳定杆。用户不在权限内的总成不要写进提案

只说“提高共用率”不算方案。要写明哪个毛坯、哪组孔不变，哪个定位面在变。

## 点名基线的部位

提案必须指出基线结构的哪一个部位同时承担了两件互相妨碍的事。常见基线：

- 前麦弗逊：滑柱上点、主销偏距、制动拖距、驱动转向
- 前双叉臂：上臂与前舱或电机包络，上点刚度与隔振
- 后五连杆：内点衬套同时决定纵向冲击和力转向；电机支架与内点若共一个刚性区，反力会带动硬点
- 扭力梁：横梁扭转刚度同时决定侧倾刚度和侧倾转向，左右轮跳动耦合
- 整体桥：跳跃和侧倾几乎绑在一起，定位杆的倾角同时管抗蹲和隔振

基线若从五连杆改成扭力梁或整体桥，原有提案通常要重写，不能只改名称。

## 值得写成矛盾的关系

每一案只留一个主矛盾。第二个效果放优选或另一案。

- 驱动反力要硬路径，内点衬套径向要软。共一个刚性凸台时，刚度只能取一个
- 抬高离地间隙，对中位置的侧倾中心和侧视摆臂角不想一起漂
- 纵向冲击要径向软，驱动纵向力下的退让方向要变成前束增加，而不是随刚度下降失去方向
- 缓冲块走完之后的力要进副车架纵梁，不要再撬内点衬套
- 两种轮距共用球笼时，伸缩量要由转向节安装面消化，而不是再做一根半轴
- 主动稳定杆或后轮转向失效后，要有一个确定的机械状态，而不是只靠控制器报故障

前悬用抗点头、主销后倾、磨胎半径、制动转向。后悬加速用抗蹲和侧视摆臂角，不要把后悬加速写成抗抬头。

“后视分量”容易被读成“向后的分量”。要写“后视图中的倾角”和“车辆纵向”。

“前束增加”在本技能里指车轮前端向车辆中心线靠拢。图说里用车辆前进方向核对，不靠正负号。

## 拥挤区，不要当创新点

这些方向可以做产品，但不要写成提案，除非多出一个新的结构关系：

- 只优化衬套刚度、空穴曲线或橡胶配方
- 常规增加 CDC、磁流变、空气弹簧找平、主动稳定杆
- 摄像头预瞄、驾驶模式、云端算法
- 把副车架改成铝或复合材料，连接和传力没有新关系
- “提高共用率”但没有说哪个孔不变
- 把三个想法收成一个“智能悬架平台”

控制只有在同时具备下面之一时才进入提案：新的作动结构、新的传感器安装关系，或失效后的机械后备。控制律放从属，不单独成页。

## 还可以挖的结构关系

这些是方向，不是现成发明。写进提案前仍要过过滤器。

- 驱动反力路径和柔度转向路径分开，并规定大冲击由谁承接
- 一个可更换件同时约束离地间隙、侧倾中心和抗蹲或抗点头，铸造本体和车身孔不动
- 缓冲块之后的第二传力路径进入副车架纵梁，内点衬套不再承接这份冲击
- 稳定杆力臂随轮跳变化，侧倾刚度在直线和转弯不同，且不靠电机
- 后轮转向锁死在零位的机械结构，锁死位置由连杆保证
- 副车架本体一种，靠机加移位覆盖两种轴距，并说明移位后衬套工作角仍在范围内

## 判据写成试验，而不是形容词

每条效果都要能回答：固定什么、改变什么、测量什么、怎样算通过。没有这四句，就还不是提案。

常用测量：

- 几何：外倾、前束、主销后倾、主销内倾、磨胎半径、侧倾中心高度、抗点头或抗蹲
- 运动学：轮跳转向、轮跳外倾、侧倾转向、侧倾外倾
- 柔度：侧向力转向、纵向力转向、回正力矩转向
- 本技能的示例把“电机反力矩引起的硬点位移”和“车轮纵向力引起的柔度转向”分成两次试验。不要用一次整车加速把两件事混在一起
- 平台：毛坯号、安装孔坐标、可更换件数量、两种状态之间谁变谁不变
- 耐久与噪声：柔性件在止挡闭合后的应变，止挡闭合时的冲击声

通过判据优先写成和基线的关系，例如“径向更软时，反力矩引起的前束仍不超过基线”。百分比和毫米等有测量后再填。状态用：待测、仿真、台架、整车、已有数据。没有数据就不要写已有数据。

## 和范例的对应

`examples/e-platform-rear` 用一个虚构的后五连杆平台演示三件不同的事：

- 提案一：电机反力不要带动内点硬点
- 提案二：抬车高时，弹簧座位移和内点位移不平行
- 提案三：斜孔决定驱动前束的方向。这一案故意标成高检索风险，用来演示“先检索、先不写交底”

不要把这三案的零件搬到用户的项目里。
