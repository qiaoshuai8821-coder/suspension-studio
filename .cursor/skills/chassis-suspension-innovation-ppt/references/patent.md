# 从结构关系到交底骨架

本技能整理的是交底素材，不是法律意见，也不是检索报告。授权与否只在检索之后由专利工程师判断。

## 过滤器

一条提案要同时满足下面各项，否则放进 `dropped`：

- 主矛盾是一个取舍，不是一个愿望
- 必要特征是结构、几何、传力或工序关系，三条到六条。拿掉任何一条，主效果就不成立
- 指出基线的哪一个部位导致失败
- 两个实施方式，第二个不是把第一个换个材料名称。差别句子里写“相对”
- 每条效果指回具体特征，并写清试验和通过判据
- 大载荷、装反或失效时，力有地方去。柔性件不单独承担冲击
- 写明跨车型哪一段不变
- 删掉同册其他提案的特征后，本案仍然成立
- 不在 domain.md 的拥挤区里直接套用
- 没有编造的试验数据、专利号、供应商
- 目标毫米和百分比不在必要特征里

改写一次仍不满足，就放弃并写原因。不要把性能形容词改写成看起来像结构的句子。

## 必要特征和优选特征

必要特征写成可以放进“其特征在于”的短句：

- 谁和谁分开，或固定在同一组孔上
- 一条轴线、合力线或位移矢量相对另一条的关系
- 哪条路径是主路径，哪条不是
- 超过工作行程或装反时，哪一个零件承接

优选特征是可以拿掉、主效果仍在的内容，例如垫片、防错、零件号共用。优选不进独立权利要求。

数值放实施方式。必要特征里留关系，例如“位移矢量不平行”，不写某个毫米。

效果特征有风险。少写“落在同一区间内”。改成几何本身，例如“纵向分量使侧视摆臂角向另一车高的摆臂角回摆”。效果放到有益效果，不放到必要特征。

## 权利要求骨架

装置：

一种用于……的悬架装置，其特征在于，包括……；其中……相对……偏置，使……；……不构成……的主传递路径；在……超过工作行程时，……闭合，载荷进入……，而不由……单独承受。

方法只有在步骤依附于结构时才写。`claim_type` 为方法或装置和方法时，必须写 `structure_basis`。纯标定步骤不写。

从属放两种实施方式、防错、垫片或另一种可拆连接。从属不要引入一个全新的发明。

每案写明三件事：

- 建议拿来对比的公开结构类型。不要编公开号。用户给了公开号才可以写
- 不要写进权利要求的内容，尤其是效果本身、配方和另一个提案才解决的问题
- 删掉其他提案后，本案为什么仍成立

检索风险分高、中、低，并写原因。高风险的默认先检索，检索前不写正式交底，也不把该特征画进先申请的附图。

## 实施例和附图

两个实施方式都要能制造。差别写在结构上：一体成型还是可更换件，机加面还是防转垫片。

图说至少包括：视图、零件、不变的部分、随车型变的部分、相对基线的差别。视图要足够让人画出侧视、后视或俯视。前束方向必须标出车辆前进方向。

幻灯片不画假的悬架几何。传力或位移示意要标明“不是几何图”。

## 分案和少公开

几案可以做在同一个安装块上，但交底必须能拆开。不要写一条把全部特征串起来的系统独立权利要求。

先申请的附图按少公开来画。组合图、垫片策略和另一案的斜孔默认留在内部评审稿，并标明不进入先申请的附图。是否保留由专利工程师在检索后决定。

同日申请还是分先后，会不会互相构成现有技术，交给专利工程师。提案里只写清“哪张图如果公开会伤到哪一案”。

## 和 PPT 的对应

| 交底章节 | 幻灯片 |
| --- | --- |
| 技术领域、背景、缺陷 | 平台边界、技术矛盾、问题页 |
| 技术问题 | 本案只做这一件事 |
| 必要特征和优选 | 方案页 |
| 有益效果和判据 | 效果页 |
| 实施方式和风险 | 实施方式页、风险条 |
| 附图说明 | 图说 |
| 权利要求骨架 | 权利要求页 |
| 分案和附图边界 | 专利族 |
| 检索前不公开 | 验证顺序、外发 |

## 不做什么

- 不检索，不引用没核对过的专利号
- 不判断新颖性和创造性
- 不把实用新型还是发明的选择写成结论。默认按发明来组织素材，是否同时申请实用新型由专利工程师决定
- 不建议在申请日前把必要特征发给供应商
