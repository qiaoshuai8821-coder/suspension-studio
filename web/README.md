# 悬架创新工作台

打开就能用。页面按两步走：01 记下想法，02 写成五页提案。手机和电脑都按屏幕宽度排版。想法存在这台浏览器里。把项目下载到自己电脑上，装好依赖后同样能用。

生成五页时，在页面里选择模型并填入你自己的密钥。默认是 DeepSeek，也可以换通义千问、Kimi、智谱或 OpenAI。密钥留在这台浏览器里；点生成时会发给本站，只为转给你选的那一家，服务器不保存。没填密钥时，按句子整理，并标明不是模型写的。同一地址每小时只能生成几次，页面会先做一次校验。

```bash
npm install
npm run dev -- -p 3847 --hostname 127.0.0.1
```
