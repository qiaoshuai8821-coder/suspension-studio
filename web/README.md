# 悬架创新工作台

打开就能用。页面按两步走：01 记下想法，02 写成两页。手机和电脑都按屏幕宽度排版。想法存在这台浏览器里。把项目下载到自己电脑上，装好依赖后同样能用。

生成两页时，在页面里选择模型并填入你自己的密钥。默认是 DeepSeek，也可以换通义千问、Kimi、智谱或 OpenAI。密钥只存在这台浏览器里，服务器用它向你选的那一家要结果，不保存密钥。没填密钥时，按句子整理，并标明不是模型写的。

```bash
npm install
npm run dev -- -p 3847 --hostname 127.0.0.1
```

写到电池会被拒绝。出来的是讨论稿，还没检索。
